# Workflow OS 0.4.0-preview.1 — Governed Authority and Repository Adoption Preview

Status: draft only; not authorized for publication

Workflow OS `0.4.0-preview.1` advances the local governance kernel around a
simple boundary:

```text
Agent executes. Workflow OS governs.
```

This preview strengthens proof-backed approval, current-authority checks,
immutable continuation, post-compaction context foundations, repository-aware
onboarding, governed workflow authoring, durable reporting, shared-state
evaluation, and narrow provider sandbox proofs.

## Highlights

- approval scope is presented and durably bound before sensitive decisions;
- resume paths reject stale or substituted execution context;
- low-risk work can complete quietly while preserving evidence and audit;
- first-run produces repository-specific posture and workflow recommendations;
- recommendations can move through inactive draft, stewardship, promotion,
  catalog, repair, and archive stages;
- a real first-run path persists an evidence-backed local WorkReport; and
- active provider identities derive from the release version.

## Important Boundaries

This remains a preview. It is not production multi-tenant hosting, a general
agent runtime, arbitrary repo command execution, broad provider mutation,
enterprise identity administration, an autonomous scheduler, agent swarms, or
Level 3/4 autonomy.

The public `v0.3.0-preview.1` release remains immutable. This draft must not be
published until final-candidate evidence, exact-commit CI, independent
assurance, and a separate governed publication decision are complete.
