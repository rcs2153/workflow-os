Release under review: **Workflow OS `0.3.0-preview.1` — Governed Execution and Continuity Preview**

This checklist prepares a release commit. Tagging, GitHub release publication,
and package publication require a separate explicit maintainer decision.

## 1. Scope And Claims

- [x] Current product contract matches implemented `main` behavior.
- [x] Hosted, OpenShell, trusted-host, PostgreSQL, and provider-write surfaces
  are labeled alpha/proof/experimental as applicable.
- [x] No broad write, arbitrary-command, autonomous-scheduler, production,
  multi-tenant, enterprise-identity, or Level 3/4 claim appears.
- [x] Mock execution is not presented as evidence of performed work.
- [x] Migration and experimental-contract warnings are visible.

## 2. Version Consistency

- [x] All four Rust crates are `0.3.0-preview.1`.
- [x] Root npm package and `@workflow-os/sdk-typescript` are
  `0.3.0-preview.1`.
- [x] `Cargo.lock` and `package-lock.json` match.
- [x] CLI text and JSON version output report `0.3.0-preview.1`.
- [x] Provider user-agent identity reports `0.3.0-preview.1`.

## 3. Required Validation

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --all-targets
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps
cargo metadata --locked --format-version 1
cargo audit
npm ci
npm run check
npm run check:contracts
npm run check:integrations
npm audit --audit-level=moderate
git diff --check
```

- [x] Every command passes, or a release blocker/accepted exception is recorded.
- [x] Opt-in live provider tests remain skipped by default.
- [ ] GitHub CI passes on the release PR head.

## 4. Documentation And Security

- [x] `CHANGELOG.md`, README, current product contract, release notes, known
  limitations, readiness, semver, and release process agree.
- [x] CLI JSON remains explicitly experimental.
- [x] `serde_yaml` trusted-local-spec risk remains visible.
- [x] No credential, authorization header, private payload, or generated local
  runtime state is staged.
- [x] Security review and dependency rationale apply to this preview.

## 5. Release Artifacts

- [x] [Release notes](0.3.0-preview.1_RELEASE_NOTES.md) are accurate.
- [x] [GitHub release draft](0.3.0-preview.1_GITHUB_RELEASE_DRAFT.md) is concise
  and accurate.
- [x] [Final release review](0.3.0-preview.1_FINAL_RELEASE_REVIEW.md) records

- [ ] Release PR is conflict-free and required checks pass.

Historical commands retained as evidence of the original release procedure.
They must not be rerun for current `main`:

```sh

```

- [ ] Decide whether GitHub Release publication is authorized.
- [ ] Decide whether Rust crates or TypeScript packages are published. Package
  publication is not automatic.
- [ ] Verify the tag points to the intended green release commit.

## 7. Rollback

Prefer a corrective preview release over rewriting public history. If a tag or
package must be removed, record the reason, follow registry policy, and rotate
any exposed credential immediately.
