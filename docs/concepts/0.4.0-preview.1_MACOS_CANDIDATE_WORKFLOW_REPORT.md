## Implementation

`.github/workflows/final-candidate-macos.yml` adds:

- manual `workflow_dispatch` with one exact source-commit input;
- read-only repository permission;
- exact equality between candidate source and workflow-definition commit;
- detached exact-source checkout without persisted credentials;
- clean-tree and native `arm64` host admission;
- pinned Rust `1.99.0` and Node `20.19.5` toolchains;
- native `aarch64-apple-darwin` release build;
- explicit `--final-candidate` packaging;
- v1 manifest, source, target, version, install, overwrite-refusal, uninstall,
  state-preservation, archive-digest, binary-digest, and binary-shape checks;
- payload-minimal evidence with publication denied; and
- pinned immutable artifact upload with seven-day retention, no overwrite, and
  no hidden files.

The workflow contains no credential, signing, notarization, release, tag,
registry, branch, pull-request, or announcement operation.

`scripts/final-candidate-workflow.test.mjs` now verifies the shared exact-source,
least-privilege, pinned-action, final-posture, and bounded-upload contract for
both workflows, plus native target-specific requirements for macOS and Linux.

## Validation

Passed:

- `npm run test:candidate-workflow`: five tests;
- YAML syntax parsing for both candidate workflow files;
- pinned Node 20 `npm run check`;
- pinned Node 20 `npm run check:integrations`;
- `npm run check:docs` through the full check;
- `npm audit --audit-level=moderate`: zero vulnerabilities after an exact
  network-enabled retry of the sandbox DNS refusal; and
- `git diff --check`.

The initial npm audit attempt failed only because sandbox DNS could not resolve
the npm registry. The exact retry completed successfully and reported zero
vulnerabilities.

No hosted workflow was run in this phase, so native hosted execution, archive
production, artifact upload, expiry metadata, download verification, and
cross-target source equality remain unproven until the separately governed
post-merge release phase.

Focused review found and corrected one admission blocker before acceptance:
the first implementation recorded binary shape without failing on a non-arm64
Mach-O result and relied on the packager to imply the exact archive filename.
The corrected workflow explicitly rejects either mismatch, and focused tests
cover both admissions.

No runtime state file was edited by hand. No repository credential, workflow
dispatch, tag, release, registry package, or announcement was created.
