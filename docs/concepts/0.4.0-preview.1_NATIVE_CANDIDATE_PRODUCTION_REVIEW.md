## Finding And Correction

### Corrected: evidence vocabulary drift

The initial release-state implementation normalized `storage_posture` to
`evidence_kind` for macOS and `storage_artifact_name` to `artifact_name` for
Linux. The values were accurate, but the unnecessary renaming weakened direct
traceability to the payload-minimal candidate evidence records.

The release state, checker, and tests now preserve the source evidence field
names. The correction changes no candidate fact, authority, or storage
posture.

No unresolved P0 or P1 finding remains in the candidate-evidence persistence
scope.

report](FRESH_CLONE_NPM_CHECK_SELF_CONTAINMENT_REPRODUCTION_REPORT.md). This
subsequent evidence does not alter this review's original bounded verdict or
