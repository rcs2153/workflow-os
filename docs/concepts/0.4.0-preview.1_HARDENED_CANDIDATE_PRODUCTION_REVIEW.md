## Review Findings

### Accepted: exact-source and evidence binding

- Exact-source CI run `42172009453` passed all nine required jobs for
  `6f8a38b080a21189dcfd82297f0c5917483b61ba` before candidate dispatch.
- Both accepted workflows used the same exact commit for source and workflow
  definition identity.
- The downloaded artifact ZIP digests match GitHub's recorded digests.
- Embedded archive checksum files pass.
- Package manifests and candidate-evidence records bind the exact source,
  target, version, final-candidate posture, clean working tree, archive digest,
  and binary digest.
- Independent extraction confirms the arm64 Mach-O and static x86-64 musl ELF
  shapes.
- The active release-state projection matches both candidate-evidence records.
- Every publication-authority field remains false.

### Accepted: prior publication blockers are corrected in the pair

The macOS candidate installer refuses dangling destination symlinks with and
without `--force`, does not write the external target, preserves normal install
and explicit regular-file replacement, removes only the installed binary on
uninstall, and preserves repository-local state.

The Linux candidate-evidence record now includes `binary_sha256`,
`binary_shape`, and `native_machine`, matching the bounded evidence surface
provided by macOS. The hosted Linux package verification completed before
artifact upload.

### Process finding: once-only dispatch was not upheld operationally

The first dispatch shell evaluated its macOS request before zsh rejected an
assignment to the reserved `status` parameter. The corrected loop then created
a second macOS run. Exact-SHA inventory exposed the duplicate; earlier run
`42173154695` remained authoritative and later run `42173175053` was cancelled
and excluded from evidence. Linux run `42173177138` was unique.

This is not an artifact-integrity blocker: only one successful attempt-1
artifact per target is admitted, the cancelled run produced no accepted
evidence, and the full history is disclosed. It is a release-process defect.
Before any future candidate dispatch, Workflow OS should replace ad hoc shell
dispatch with an idempotent exact-source helper or connector path that records
the requested transition, reconciles ambiguous responses before retry, and
fails closed when an exact-source run already exists.
