## Implemented Boundary

The workflow:

- accepts only a manual `workflow_dispatch` request with one exact lowercase
  40-character source commit;
- requires the candidate source commit to equal the reviewed workflow
  definition commit and the source package identity to equal
  `0.4.0-preview.1`;
- checks out that commit with persisted Git credentials disabled;
- verifies `HEAD` and a clean tracked and untracked source tree;
- grants only `contents: read` repository permission;
- pins checkout, Rust toolchain, Node setup, and artifact upload actions to
  exact 40-character revisions;
- pins Rust `1.99.0` and Node `20.19.5` for this candidate lane;
- builds the Linux x86-64 musl binary with the locked Cargo graph;
- invokes the packager only through `--final-candidate`;
- verifies checksum, v1 manifest, exact source, final posture, target, version,
  install, overwrite refusal, idempotent uninstall, and state preservation;
- writes a payload-minimal evidence record with source commit, workflow
  definition commit, workflow run, storage and archive names, archive checksum,
  target, selected toolchain versions, retention, and explicit non-publication
  posture; and
- uploads exactly the candidate archive, checksum, and evidence record with
  seven-day retention and overwrite disabled.
