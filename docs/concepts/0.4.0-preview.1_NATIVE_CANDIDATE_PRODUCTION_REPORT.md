## Validation And Boundaries

The candidate-production phase verified both package contracts and the exact
source CI result. This follow-up implementation makes those facts part of the
machine-checked release state. It does not reproduce either build.

An external evaluator separately reported a fresh-clone `npm run check`
failure when `target/debug/workflow-os` had not been created. A later governed
clean-room replay on current `main` disproved that distinct claim: the
advertised command passed after beginning without the debug binary because the
SDK validation path built it. The exact procedure and one corrected evaluator
environment mistake are disclosed in the [reproduction
report](FRESH_CLONE_NPM_CHECK_SELF_CONTAINMENT_REPRODUCTION_REPORT.md).

Independent release and security assurance remains open. Owner-conducted
governed review and external product evaluation are useful evidence, but they
are not represented as independent release-security acceptance.
