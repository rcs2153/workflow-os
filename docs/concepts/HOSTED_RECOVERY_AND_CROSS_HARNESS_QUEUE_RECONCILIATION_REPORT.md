## Why The Queue Changed

The closed **Accepted Means Dispatched** gate repaired a known posture in which
the durable run prefix existed but queue insertion failed. New fault injection
reports a distinct earlier gap: failures before validation, start, or step
scheduling can survive as partial runs that ordinary exact retry cannot finish.
This is a concrete correctness and operator-recovery defect on the public
hosted path.

The product critique also identifies a sequencing imbalance. Additional
private obligation derivation can improve internal inspectability, but it does
not test whether a second execution host can safely continue real work from the
same governed record. Cross-harness continuation tests the adoption thesis more
directly while preserving Workflow OS as the governor rather than the agent or
sandbox runtime.

## Benchmark Interpretation

The reported post-compaction token result replicated: approximately `50.1%`
fewer gross recovery tokens versus `49.9%` previously across six observed
Codex compactions, with all nine tested decisions correct in both approaches.

That is useful evidence, but the claim remains bounded:

- both approaches received Workflow OS evidence;
- the lookup approach incurred an additional evidence-reconstruction turn;
- cache hits narrowed the difference in uncached input plus output;
- authoritative billed cost was not measured; and
- the evaluation does not establish generalization across tasks, models, or
  hosts.

The stronger product claim is continuity and reuse of the authoritative record:
the same record a reviewer uses to inspect a run can orient a replacement
harness about what was approved, denied, completed, blocked, and still lawful.
