## Findings

agreement between the machine-readable release-state version and the active
package version, but focused tests did not exercise either rejection path.

Two negative tests now prove that:

  and
- active release-version drift fails closed.

### Accepted design boundary

The checker is deliberately active-release specific. It verifies that the
known PR #712 and PR #713 merge commits are ancestors of the current checkout,
their implementation surfaces exist, and exact PR/commit facts appear in the
roadmap, accepted plan, and implementation reports. It rejects pending
transition language in those active authority surfaces and requires the
merged-workflow checklist gate to be closed.

The record does not authorize candidate dispatch or publication. A later
release version must replace or extend this active-release record rather than
silently inheriting `0.4.0-preview.1` facts.
