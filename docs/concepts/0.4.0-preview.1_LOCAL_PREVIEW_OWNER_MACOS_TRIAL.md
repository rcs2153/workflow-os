## Corrections And Limits

The first harness attempt wrongly expected exit 1 for terminal `next-action`.
It stopped on the actual intended exit 3. The expectation was corrected against
the CLI mapping, a new disposable trial completed, and both attempts' logs and
state were preserved. Its isolated installation was removed afterward. No
kernel state was edited to make a test pass. An initial SQLite read-only open
failed in the sandbox; an immutable read-only URI worked without state edits.

This trial did not exercise crash-gap fault injection, full approval-grant and
changed-fact rejection, independent macOS repetition, Linux native user paths,
external repositories owned by real users, or hostile-host attestation.
Trusted local operator and filesystem ownership remain part of the boundary.
Independent current-feed audit [#971](https://github.com/rcs2153/workflow-os/issues/971)
and exact-pair/local acceptance [#974](https://github.com/rcs2153/workflow-os/issues/974)
remain open. No independent verdict or assigned evaluator is inferred.
