## Implementation

`ContinuationProjectionDelivery` now carries the decision's bounded typed gaps
and binds them into the exact delivery commitment. A recipient therefore cannot
receive only a generic blocked posture while the bounded reason disappears.

The private replacement-executor conformance boundary:

- independently delivers one exact aggregate to an original recipient and a
  distinct context-free replacement recipient;
- requires the same exact aggregate proof, understanding commitment, typed
  claims, typed gaps, and decision posture;
- validates an exact non-authorizing delivery acknowledgment for each
  recipient;
- rejects a lawful next option whose exact canonical value matches a completed
  obligation;
- calls a separate fresh-authority resolver only after exact equivalence and a
  `ReadyForAuthorityResolution` posture; and
- never supplies the projection, delivery, or acknowledgment as an authority
  credential.

The authority resolver returns no authority payload to the proof. The proof
records only `resolved_separately` or `not_requested_blocked`, preventing the
conformance record from becoming a serialized capability or approval token.
